Because it transfers executable bytes to repository-hosted storage, this is a real retention/transfer decision, not merely JSON publication. Do not describe the public-repository artifact as a private release vault.
- Coordinator destination: one exclusive local directory `/tmp/auto-derived-pair-retained-<actual-run-id>` after the sole verified artifact download. No user computer, phone, global installation or runtime search path. Preserve bytes without executing or loading them.
- Lifetime: the hosted copy expires after 14 days. The proposed local policy is to retain evidence for the owner’s destination/disposal decision and review it before hosted expiry. However, `/tmp` and the execution workspace are best-effort ephemeral storage and may be lost earlier; neither the local policy nor the 14-day hosted setting promises a durable backup. Do not silently delete or claim continued availability without readback. No automatic promotion to the working package or runtime allowlist.
- Only the existing owned build scratch may be cleaned by its reviewed identity-bound cleanup. Retention must be independently verified before scratch cleanup can be called successful evidence preservation. A partial copy, hash mismatch, uncertain writer/process lifetime or unknown file retains failure and cannot upload a success artifact.
