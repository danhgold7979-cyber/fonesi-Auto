## 5. Exact bounded gap/fold algorithm

For each snapshotted civil occurrence create two actual `Temporal.ZonedDateTime.from(privateFields,{overflow:'reject',disambiguation:'earlier'})` and `...disambiguation:'later'` values. This API is documented at https://tc39.es/proposal-temporal/docs/zoneddatetime.html . Never use default/compatible disambiguation, because it can shift a gap into an actual instant rather than implement SKIP.

Before classifying, capture both successful library results into private scalar records. Require native `bigint` epochNanoseconds; `ns % 1000000n === 0n`; derive ms by bigint division, require it within ±Number.MAX_SAFE_INTEGER before Number conversion, and require exact equality to the library's safe signed epochMilliseconds. Never convert epoch nanoseconds directly to Number. Require offsetNanoseconds to be a safe integer divisible by1000000000, derive integer offsetSeconds with absolute value<86400, and reject negativezero/nonfinite/fractional components. Returned ISO calendar fields must be complete, real and coherent with the instant+offset scalar; local subsecond fields must be zero. Offset seconds may be nonzero within a minute: never round historical offsets.

Let L be the requested ISO local civil scalar in integer milliseconds (computed from validated civil fields without host-zone parsing); E/T the earlier/later epoch ms; oE/oT their actual offsets in milliseconds; LE=E+oE and LT=T+oT the returned local scalars. Independently require each returned PlainDateTime exactly represents its corresponding local scalar; this arithmetic is a coherence check, not a custom inverse/transition search. Displaced locals may lie just outside the admitted request-date interval. Then exact branches are:
1. UNIQUE iff both local roundtrips equal L, E===T, and oE===oT.
2. OVERLAP_EARLIER iff both local roundtrips equal L, E<T, oE>oT, and T-E===oE-oT. Return E once; no second executable row.
3. SKIPPED_GAP iff neither local roundtrips equal L, E<T, oT>oE, delta=oT-oE is positive and <=86400000ms, T-E===delta, LE===L-delta and LT===L+delta (therefore LE<L<LT). Both library inversions must have succeeded; no shifted instant is returned as a scheduled occurrence.
4. One-sided match, equal epochs with unequal offsets, incoherent fields/arithmetic, unexpected ordering or any thrown call => RESOLUTION_UNAVAILABLE; invalid numeric representation => FORMAT_UNSUPPORTED. No RangeError is interpreted as gap and no default-compatible shifted result becomes success.

This uses public library disambiguation rather than an application-owned transition search. Historical second offsets are permitted if exact integer seconds/milliseconds; no assumed ±1hour shift. Preserve all civil rows and original counting. At most2×(4096+1)=8194 library inversions plus finite zone/runtime checks per call; internal library complexity is pinned/reviewed, not invented constant-time. Named-zone cache cardinality is constrained by the captured finite admitted list, not arbitrary caller strings. No timers/retries/resolver callbacks. Structural bounds are not latency claims; measurement may later justify a smaller explicit batch/owned-worker boundary, not an unreviewed scheduler.
