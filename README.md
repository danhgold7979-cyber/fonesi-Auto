# fonesi-Auto

New working repository for the AutoReels Studio project.

The implementation baseline is being brought over from `danhgold7979-cyber/fonesi-W` on `feat/studio-workspace`. The reference repository will remain unchanged. Application code will be introduced on short-lived feature branches and merged only through reviewed pull requests after the required checks pass.

Product scope: a Windows desktop studio for managing Android devices, fixed app-specific posting workflows, content/media inputs, per-device/per-account schedules, execution safety, verification, history and recovery.
