## 4. Fixed version1 processing semantics

Pipeline ID `SUPPLIED_OPENCV_PREPROCESS_V1`. Request operation contains only integer ROI `{x,y,width,height}`, scale enum `HALF|ONE|DOUBLE`, contrast enum `IDENTITY|GAIN_125`. No interpolation/kernel/alpha/beta/string selector from caller.

Input IHDR must have positive dimensions <=4096 each, <=4194304 pixels, RGB8 or RGBA8, checked before inflate by the fixed preprocessing decoder path. Output independently obeys both4096-axis and4194304-pixel caps. Require alpha255 for every RGBA pixel; other alpha returns UNSUPPORTED_ALPHA, not silent compositing. Convert admitted RGB to opaque RGBA by the fixed implementation. Reject invalid/empty/out-of-bounds ROI, multiplication/stride overflow, oversized output and HALF when either ROI dimension is odd. Scale is exact rational1/2,1 or2; output dimensions are exact integers preserving aspect ratio, no independent width/height stretch. Orientation is not changed; captured rotation/orientationEpoch remain attribution, not permission to rotate.

Worker snapshots contiguous uint8 RGB planes, crops the exact ROI, calls `cv2.resize` using INTER_AREA for HALF and INTER_LINEAR for DOUBLE (ONE copies), then fixed linear gain: IDENTITY copies; GAIN_125 uses `cv2.multiply(rgb.astype(numpy.float32), numpy.full(rgb.shape, 1.25, dtype=numpy.float32))`. All possible values are exact quarter integers; explicitly round half-up with `numpy.floor(gained + 0.5)`, clip to[0,255], cast uint8. No convertScaleAbs/platform-dependent tie rounding. Alpha stays255. This is a versioned transform, not guaranteed readability improvement. All-dark/all-light and saturated outputs remain visibly attributable; report RGB-only minimum/maximum of final output channel values and clippedChannels equal the number of RGB channels whose pre-round/pre-saturation gained value exceeds255 (IDENTITY zero; alpha excluded), never fabricate usable text/confidence. Unsupported/corrupt/extreme dimension input refuses; poor visual content may still be a correctly transformed image, not a recognition success.

Mapping records original width/height, ROI and exact scale numerator/denominator. Source edge coordinates are `x=roi.x+outputX*denominator/numerator` and equivalent y; forward inverse is exact rational within ROI. Mapping is reversible geometry, **not lossless image reconstruction after downsampling**. For rectangles, preserve exact rational edge values; a separate explicit conservative integer covering rectangle uses floor left/top, ceil right/bottom and checks image bounds. No tap point is emitted. Every returned mapping binds pipeline ID, `sourcePixelSha256` of original decoded RGB/RGBA bytes and separate `inputSha256` of the exact opaque RGBA wire bytes, request/capture/device/binding/generation/orientation and current supplied context revision.

### Exact owner/operation lifecycle and supplied-context fence
`begin(request:unknown)` synchronously returns either `{accepted:false,code:'BUSY'|'CONTEXT_CHANGED'|'WORKER_UNAVAILABLE'}` or `{accepted:true,operation}`. Reservation stores private operation identity, generation and monotonic10s deadline before queuing any descriptor snapshot/decode or process callbacks; caller receives cancel handle first. No external clock/current/dispatch callbacks are production options. Monotonic timer is module-owned; tests may transform fixed source seams explicitly, not expose an authority constructor.

Context mismatch, disconnected state or existing capture freshness/orientation failure refuses processing. PNG evidence must pass existing capture classification using internally captured UTC, never caller-controlled current time.

After every trap-bearing operation and after decode the outer work rechecks private identity/generation/cancel/deadline before progressing. Final publication performs only comparisons of captured immutable scalars/private state, with no property reads from untrusted request/context/result objects and no external callbacks between fence and result assignment.
